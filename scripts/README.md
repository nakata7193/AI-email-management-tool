# Scripts Directory

Utility scripts for development, testing, and maintenance.

## Contents

- `test-setup.sh` - Setup script for testing environment
- `test_move_emails.py` - Script to test email moving functionality
- `workflow.sh` - Development workflow automation script

## Usage

These scripts are for development and testing purposes only. They are not part of the main application.

### Running Scripts

```bash
# Make scripts executable
chmod +x scripts/*.sh

# Run a script
./scripts/test-setup.sh
```

### Testing Scripts

```bash
# Run Python test scripts
python scripts/test_move_emails.py
```
