================================================================================
KEY FINDINGS
================================================================================

1. Larger batches are both faster AND cheaper
   - 10 emails/batch: 191s, $0.73
   - 1000 emails/batch: 46s, $0.68

2. Token overhead decreases with larger batches
   - The prompt template (~200 tokens) is sent once per batch
   - With batch=10: 100 batches × ~200 = ~20k tokens wasted on repeated prompts
   - With batch=1000: 1 batch × ~200 = ~200 tokens

3. Output tokens stay consistent (~4.5 tokens per email regardless of batch size)

================================================================================
RECOMMENDATIONS
================================================================================

Fastest:  batch_size=1000 (45.68s, 1 API calls)
Cheapest: batch_size=1000 ($0.6807)

Practical recommendation: batch_size=100-200
- 100: Good balance (63s, 10 API calls) - easier error recovery
- 200: Faster (53s, 5 API calls) - good for stable connections
- 1000: Fastest but risky - if one fails, you lose the whole batch
