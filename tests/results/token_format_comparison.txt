COMPACT FORMAT:
---------------
Categorize these 10 emails.

1. Subject: ...
   From: ...
   Body: ...

Categories (use ONLY these, use "other" if unsure): receipt, shipping, ...

Response: one line per email
<number>. <category>

Example:
1. shipping
2. promotional
3. other


JSON FORMAT:
------------
Analyze these 10 emails and categorize each based on CONTENT, not just sender.

EMAIL 1:
- ID: ...
- Subject: ...
- From: ...
- Body Preview: ...

**Available Content Categories:**
- receipt: receipt
- shipping: shipping
...

**Response Format (JSON array, one object per email):**
[
  {"email_id": "id1", "content_category": "category", "importance": "high/medium/low", ...},
  ...
]

EVOLUTION OF COMPACT FORMAT
================================================================================

Version 1 (with importance + flags):
  1. shipping H RT
  2. promotional L
  3. personal M A

Version 2 (flags only):
  1. shipping RT
  2. promotional
  3. personal A

Version 3 (category only - FINAL):
  1. shipping
  2. promotional
  3. personal

Rationale:
- Importance is determined by category config, not AI
- Flags (receipt/tracking/action) were not needed for organization
- Simpler = fewer tokens = lower cost
